# --- numeric helpers used in the catchment / drive-time layer ---
# NOT pinned deliberately: basemap constrains numpy, and pinning both here means one of
# them loses. Installing basemap into a Python that already has a newer numpy DOWNGRADES
# it (2.5.1 to 2.3.5 on 7 August 2026), and on Windows the old version's files are often
# locked and left behind as ~-prefixed folders in site-packages, which then breaks the
# import. Build the venv first and install everything into it in one pass. check_env.py
# looks for exactly that wreckage.
numpy

THE SEATS CROSS-CHECK. The QSI engine estimates demand from catchment and capture knowing
nothing about the aircraft; seats times a constant estimates it from the aircraft knowing
nothing about the market. Two independent readings, so disagreement carries information.
seats_crosscheck.py joins the arm to launch_profile for clean seats, since LF-MEASUREMENT-VOID
killed the arm's own capacity column, restricts to long-haul international FSC, and scores
five rules on captured_uncapped against p2p_outturn. k, the band and the threshold are all
learned leave one cohort out.

THE CONDITION IT RESTS ON, and it belongs on the page as much as in the code. Seats only
carry information when the gauge is somebody else's judgement. True by construction in the
back-test, true when a client brings a proposed aircraft, false when the tool picks the gauge
or a user sweeps frequencies. Any feature built on this has to know which case it is in.

  own od_source block and can only name DOT DB1B when DOT was read. Three outcomes:
  a run with no od_source block or an all-Sabre run keeps the existing line; an

  markets and Sabre for the rest, which is the true sentence and still the one that
  sells. Tested on all four contract shapes.
